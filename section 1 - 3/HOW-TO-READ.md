# How to Read Section Files Properly

This guide explains how to preview `section-1.md`, `section-2.md`, and `section-3.md` using **Markdown Live Preview**.

---

## Tool

**Markdown Live Preview**  
URL: [https://markdownlivepreview.com/](https://markdownlivepreview.com/)

No account or installation required. Works directly in the browser.

---

## Steps

### 1. Open the Target File

Open one of the following files in your code editor (e.g. VS Code):

| File | Content |
|---|---|
| `section-1.md` | JobStreet Indonesia – Registration Test Case Document |
| `section-2.md` | Bug Report – JPetStore Demo Application |
| `section-3.md` | QA Automation Questions |

---

### 2. Copy the File Content

Select all content in the file using **Ctrl + A** (Windows/Linux) or **Cmd + A** (Mac), then copy with **Ctrl + C** / **Cmd + C**.

---

### 3. Open Markdown Live Preview

Go to [https://markdownlivepreview.com/](https://markdownlivepreview.com/) in your browser.

---

### 4. Paste the Content

Click inside the **left panel** (editor area) of the page, clear any existing content, then paste with **Ctrl + V** / **Cmd + V**.

---

### 5. View the Rendered Output

The **right panel** will instantly render the formatted output including:

- Headings and sections
- Tables with proper alignment
- Bold text and bullet points
- Horizontal dividers
